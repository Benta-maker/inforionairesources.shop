## The rule

**One entry per machine-facing change, appended at execution time, not retrofitted.**

A change is **machine-facing** if it touches any of:

- `robots.txt`
- `sitemap.xml`
- `llms.txt`
- any JSON-LD block (`<script type="application/ld+json">`)
- any `<meta>` tag, including `og:` and `twitter:` properties
- any `<link>` element carrying a machine-directed relation — `canonical`, `alternate`, `icon`
- any file generated by `tools/generate-machine-layer.py` once it exists (B-20)

**The entry lands in the same commit as the change it records.** That is B-16's acceptance criterion, and it is the only thing that makes the log trustworthy: a log written afterwards records what someone remembered, not what happened.

**"Who decided" names a human being.** Not a role, not the property, not the implementing agent. D-9 requires attribution to a human decision; a name is what discharges that. Where the implementing agent proposed the change and a human approved it, the human is named — the agent is not the decider.

**Where a decision has a cost, name the cost.** A log that records only what was gained is a marketing document. Where a change forfeits something — a capability, a protection, an option — the "what changed" column says so.

## Open debt carried by an entry above

**B-2 leaves one limb of D-9 undischarged, and B-7 discharges it.**

It does not publish the equivalent: the brief's specified comment block ended with `Human-readable equivalent: /terms.html`, and `/terms.html` returns 404 on this property. Shipping a pointer to a page that does not exist would assert a fact the site does not carry, which P-14 forbids, so the convener ruled the line dropped rather than shipped broken.

**Owner: B-7** — "Restore or de-reference the missing standard pages". When B-7 ships `/terms.html` returning 200, the `Human-readable equivalent: /terms.html` line is restored to `robots.txt` in the same commit, and that commit appends its own entry here closing this debt. Until then the reservation in `robots.txt` stands without a human-readable counterpart, and this is a known gap, not an oversight.

**Owner: B-11** — "Repair every dangling reference in the machine layer", whose scope is exactly this, and which by OD-J is executed by the generator rather than by hand. Recorded here so the finding is not lost between the task that found it and the task that fixes it.
